# BAL Coding Tracker

VS Code extension for tracking active coding time by project and programming language.

## Features

- Track active coding time
- Track coding sessions
- Detect the current project
- Detect programming language
- Store coding data locally as JSON
- Display current coding time in the VS Code status bar

## Data Storage

Coding activity is stored locally as JSON.

No backend connection is required.
